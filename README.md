# OneClick&GO

Official distribution repository for OneClick&GO for Windows.

This repository contains installers, release notes and license documents.
The application's source code is not published here.

## Downloads

Download installers from [Releases](https://github.com/OmarLarbi/OneClickGO/releases).

Each release includes:
- The Windows installer.
- `SHA256SUMS.txt`, used to verify the downloaded installer's integrity.

Installers marked as test versions are intended for evaluation and may contain
errors. Read the release notes before installing.
